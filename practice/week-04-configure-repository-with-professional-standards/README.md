# Configure Repository with Professional Standards

## Task Brief
Set up .gitignore, branch protection rules, and CI/CD hooks in your capstone repository for team collaboration.

## Scenario
Your team requires professional repository standards before merging production code. Configure protection rules and automation.

## Deliverables
- .gitignore file with Python exclusions
- Branch protection rules configured

## Success Criteria
- Protection rules prevent direct main pushes
- Automated checks run on pull requests
