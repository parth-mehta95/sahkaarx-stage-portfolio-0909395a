# Practice Daily Git Workflow and Branching

## Task Brief
Create feature branches, commit changes, push updates, and pull team changes in realistic scenarios.

## Scenario
Simulate a week of team development: create feature branches, commit changes, push updates, and pull team changes safely.

## Deliverables
- Feature branch with 5+ meaningful commits
- Pull request with clear description
