# Practice Daily Git Workflow with Core Commands

## Task Brief
Master add, commit, push, and pull commands through realistic daily development scenarios in your capstone.

## Scenario
Simulate a week of team development: create feature branches, commit changes, push updates, and pull team changes safely.

## Deliverables
- Feature branch with 5+ meaningful commits
- Pull request with clear description

## Success Criteria
- Commits follow conventional message format
- All changes pushed to remote repository
