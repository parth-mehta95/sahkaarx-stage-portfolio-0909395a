# Create and Resolve Merge Conflicts Across Branches

## Task Brief
Create conflicting branches in your capstone repository, practice identifying conflicts, and resolve them using Git conflict resolution tools.

## Scenario
Simulate a team scenario where two developers modify the same file; create conflicting branches and practice safe conflict resolution.

## Deliverables
- Two conflicting feature branches
- Resolved merge with conflict markers handled

## Success Criteria
- Conflicts identified and marked correctly
- Resolution preserves both code intents
